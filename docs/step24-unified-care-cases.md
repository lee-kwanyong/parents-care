# STEP24 통합 케어 케이스

## 목적

지금까지 만든 기능을 하나의 케이스로 묶는다.

보호자는 식사, 약, 서류, 매니저, 비용, 리포트를 따로 보지 않는다.
부모님 걱정 하나가 어디까지 진행됐는지를 한 화면에서 본다.

## 추가 기능

- 통합 케어 케이스
- 케이스 링크
- 통합 타임라인
- 최근 데이터 자동 연결
- 가족용 케이스 안심판
- 운영실 케이스 보드
- 케이스 상태 변경

## 연결 대상

- 걱정 접수
- 사진·카톡 접수
- 케어패스포트
- 밥·약·컨디션 확인
- 가족 할 일
- 보험서류·영수증
- 정기진료·다음 예약
- 퇴원 후 7일
- 안심밥상
- 사회공헌
- 연락센터
- 30초 요약
- 매니저 현장
- 추가비용 승인

## 화면

- /care-cases
- /child/cases
- /ops/cases

## 40대 이상 UX 원칙

- 가족은 기능별 메뉴를 찾아다니지 않는다.
- 하나의 케이스에서 안심/확인 필요/긴급을 먼저 본다.
- 가족 할 일은 3개 이하로 먼저 보여준다.
- 운영실은 흩어진 기능을 케이스로 묶어 관리한다.
