# 매니저 현장 체크

## 목적

매니저가 Android PWA에서 큰 버튼만 눌러 현장 진행을 기록한다.

## 단계

1. 출발했습니다
2. 부모님을 만났습니다
3. 병원/장소에 도착했습니다
4. 접수·수납을 도왔습니다
5. 진료/업무가 끝났습니다
6. 약국·복약 확인했습니다
7. 귀가 확인했습니다
8. 리포트까지 완료했습니다

## 결과

- manager_field_check_events 에 단계별 기록 저장
- manager_field_assignments 상태 변경
- 리포트 완료 시 care_manager_earnings 에 정산 예정 생성
