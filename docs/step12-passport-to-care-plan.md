# STEP12 케어패스포트 → 케어플랜 자동 반영

## 목표

부모님 상태 정보가 단순 저장으로 끝나지 않고 운영실 케어플랜에 자동 반영되게 한다.

## 반영되는 정보

- 오른쪽/왼쪽 귀가 잘 안 들림
- 오른쪽/왼쪽 다리 통증
- 무릎, 허리, 어깨 통증
- 보행 불편
- 시력 불편
- 낙상 위험
- 알러지 유무
- 복용 중인 약
- 식사 제한
- 응대 방식
- 긴급 메모

## UX 원칙

- 가족에게는 질문 3개 이하
- 가족에게는 할 일 3개 이하
- 매니저에게는 현장 주의사항으로 변환
- 운영실에는 체크리스트로 변환
- 부모님에게는 부담 없는 표현만 사용

## 현재 연결

- /care-passport 에서 상태 저장
- /ops/plan-builder 에서 케어패스포트 반영 플랜 생성
- /care-request/status/[id] 에서 가족용 플랜 확인
