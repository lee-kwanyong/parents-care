# 부모님 케어 플랫폼 제품 원칙

이 프로젝트는 병원동행 매칭앱이 아니라 **부모님 걱정을 해결해주는 케어 플랫폼**이다.

## 개발 끝날 때까지 절대 잊지 않을 기준

1. 핵심 사용자는 40대 이상 자녀다.
2. 조금만 어렵고 복잡하면 이탈한다.
3. 기능은 제대로 있어야 하지만, 고객 화면은 간편하고 간결해야 한다.
4. 사용자는 기능을 고르지 않는다. 걱정을 누른다.
5. 앱 입력이 어려우면 전화, 카톡, 사진으로 맡길 수 있어야 한다.
6. 부모님 화면은 큰 글씨, 큰 버튼, 오늘 필요한 정보만 보여준다.
7. 사회공헌은 부가기능이 아니라 제품 철학이다.

## 한 문장 정의

> 부모님 병원·식사·약·안부·서류·퇴원 후 케어를 가족 대신 쉽게 정리해주는 부모님 케어 플랫폼.

더 짧게는:

> 부모님 걱정을 간단히 맡기는 앱.

## 기존 병원동행/매칭앱과 다른 점

| 기존 관점 | 우리 관점 |
|---|---|
| 매니저를 연결한다 | 걱정을 접수해서 해결 플랜으로 바꾼다 |
| 병원 가는 날만 지원한다 | 병원 전·중·후와 식사·약·서류·다음 예약까지 챙긴다 |
| 사용자가 기능을 찾아야 한다 | 사용자는 걱정만 선택한다 |
| 앱 입력을 전제로 한다 | 전화·카톡·사진 접수를 기본으로 둔다 |
| 단건 서비스 중심이다 | 케어패스포트와 정기 케어로 반복 품질을 높인다 |
| 결제 가능한 고객 중심이다 | 취약가정 쿠폰, 공공지원, 무료 안부 확인을 함께 설계한다 |

## 핵심 기능 묶음

### 걱정 접수센터

첫 화면에서 기능명이 아니라 걱정을 선택한다.

- 병원에 혼자 못 가세요
- 밥을 잘 못 챙겨 드세요
- 약을 잘 드시는지 모르겠어요
- 퇴원 후 집에서 걱정돼요
- 보험서류가 필요해요
- 정기진료를 계속 챙겨야 해요
- 뭘 해야 할지 모르겠어요

### 케어팩

기능을 낱개로 찾지 않게 상황별 묶음으로 제공한다.

- 병원 가는 날 안심팩
- 안심밥상 케어
- 약 챙김 안심팩
- 퇴원 후 7일 안심팩
- 보험서류 챙김팩
- 정기진료 자동관리
- 정기 안부 확인
- 뭘 해야 할지 모르겠어요 상담

### 케어패스포트

부모님을 알수록 서비스가 좋아져야 한다.

- 거동
- 청력/시력
- 식사 제한
- 복용약
- 낙상 위험
- 말투/응대 방식
- 긴급 연락처
- 공유 범위

### 안심밥상

병원보다 더 자주 생기는 식사 걱정을 포함한다.

- 식사 확인
- 식사 미확인 알림
- 정기 도시락/밑반찬 연결
- 저염식/연화식/죽/회복식 상담
- 식사 리포트

### 사회공헌

돈이 큰 목적이 아니라면 제품 안에 반드시 있어야 한다.

- 취약가정 안심 쿠폰
- 공공 병원동행/식사 서비스 안내
- 무료 안부 확인 캠페인
- 지역 복지기관 연결
- 비용 부담 상담

## UX 원칙

- 홈 화면 CTA는 4개 이하로 유지한다.
- 핵심 행동은 3번 안에 끝낸다.
- 사용자가 모르면 “잘 모르겠어요”로 접수한다.
- 모든 세부 기능은 운영실에서 대신 정리할 수 있게 한다.
- 리포트보다 먼저 안심/확인 필요/긴급 상태를 보여준다.
- 부모님 화면은 메뉴가 아니라 큰 버튼이다.
