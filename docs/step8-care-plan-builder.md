# STEP8 걱정 기반 케어플랜 빌더

## 목표

40대 이상 보호자가 기능을 찾지 않고 걱정을 접수하면, 운영실이 버튼 하나로 가족용 간편 케어플랜을 만든다.

## 추가된 흐름

1. /care-request 에서 걱정 접수
2. /ops/plan-builder 에서 케어플랜 생성
3. /care-request/status/[id] 에서 가족용 간편 플랜 확인

## 40대 이상 UX 기준

- 질문은 3개 이하
- 가족 할 일은 3개 이하
- 전화/카톡/사진 접수를 기본으로 둔다
- 부모님 화면은 큰 글씨, 큰 버튼
- 인증은 배포 직전에 연결한다
- 사회공헌 연결은 제품 안에 둔다

## 포함한 케어 범위

- 병원 가는 날 안심팩
- 안심밥상 케어
- 약 챙김 안심팩
- 퇴원 후 7일 안심팩
- 보험서류 챙김팩
- 정기진료·정기케어 자동관리
- 정기 안부 확인
- 뭘 해야 할지 모르겠어요 상담
- 추가비용 사전승인
- 같은 매니저 우선 배정
- 사전 안심전화
- 사회공헌 연결
