# UI Mobile Foundation

## 목적

기능이 많아졌기 때문에 화면을 다시 40대 이상 보호자 기준으로 정리한다.

## 적용 기준

- 모바일 우선
- 큰 버튼
- 첫 화면 기능 4개 이하
- 걱정 중심
- 안심 / 확인 필요 / 긴급 먼저 노출
- 가족 할 일 3개 이하
- 부모님 화면은 초대형 글씨
- 운영실은 우선순위 보드 중심
