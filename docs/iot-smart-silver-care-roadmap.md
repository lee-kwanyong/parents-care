# IoT 스마트 실버 케어 로드맵

## 현재 기반

- parents-care.net 운영
- 부모님 안부 입력
- 자녀 안부지문 리포트
- 가족 실행 보드
- 지자체 운영실
- 사례관리·성과보고 초안

## IoT 고도화 방향

### 스마트 복약통

수집 데이터:
- 약통 개폐 시간
- 복약 예정 시간
- 예정 시간 초과 미개봉
- 일일 복약 이행률

지자체 활용:
- 복약 미확인 대상자 소팅
- 가족 확인 요청
- 담당자 전화 확인
- 월간 복약 이행률 보고

### UWB 비접촉 레이더

수집 데이터:
- 재실·부재
- 무활동 시간
- 낙상 의심 이벤트
- 호흡 저하 의심 이벤트

지자체 활용:
- 고위험군 우선 적용
- 야간·새벽 위험 신호 관제
- 방문 필요 후보 선별
- 응급안전망 연계 가능성 검토

## 개인정보 원칙

- 카메라 영상 수집 배제
- 음성 수집 배제
- 물리 이벤트 데이터 중심
- 가족코드 기반 최소 식별
- 동의 기반 공유
