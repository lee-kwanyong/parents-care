# 생활 편의 레이어 설계

안심 체크인/SLA는 사고를 줄이는 안전 레이어입니다. 이번에 추가한 생활 편의 레이어는 사용자가 실제로 매번 귀찮아하는 일을 줄이는 레이어입니다.

## 왜 필요한가

병원동행 서비스에서 사용자가 가장 많이 겪는 불편은 예약 자체보다 다음 항목입니다.

- 신분증, 복용약, 질문, 결제수단을 까먹음
- 병원 정문, 접수층, 휠체어, 화장실, 약국, 귀가 대기 위치를 매번 물어봄
- 보험 청구용 서류와 영수증을 뒤늦게 찾음
- 진료 후 약 복용 확인과 다음 예약을 가족 중 누가 할지 정해지지 않음
- 카톡, 전화, 리포트에 정보가 흩어짐

## 추가된 기능

### 1. 오늘 준비팩

`appointment_preparation_items`에 일정별 준비물을 자동 생성합니다.

- 신분증 또는 모바일 신분 확인 수단
- 현재 복용약 목록 또는 약 봉투 사진
- 의사에게 물어볼 질문 리스트
- 결제수단과 소액 현금
- 물, 겉옷, 보행 보조 물품
- 택시 하차 위치와 접수층 확인

### 2. 병원 동선 가이드

`hospital_visit_guides`에 병원별 편의 정보를 저장합니다.

- 정문/접수층
- 택시 하차 위치
- 귀가 대기 위치
- 휠체어 대여 위치
- 화장실/엘리베이터 힌트
- 약국 위치
- 주차 안내
- 매니저 현장 팁

### 3. 서류·영수증 요청함

`appointment_document_requests`에 보호자가 요청한 서류를 일정별로 저장합니다.

- 진료비 영수증
- 진료비 세부내역서
- 통원확인서
- 처방전 사본
- 검사 결과지

민감정보가 섞일 수 있으므로 `required_consent_scope`를 함께 저장합니다.

### 4. 복약 확인 알림

`appointment_medication_reminders`에 진료 후 가족 확인 알림을 저장합니다.

- 약 이름
- 용량
- 복용 시점
- 확인 담당자
- 확인 시간

### 5. 다음 예약 후보

`next_visit_candidates`에 리포트 속 다음 예약 안내를 일정 초안 후보로 저장합니다.

- 정기 재진
- 물리치료
- 검사 예약
- 보호자가 병원에 전화해야 하는 예약 후보

### 6. 가족 할 일 보드

기존 `guardian_tasks`를 확장해 담당자 라벨, 우선순위, 편의 카테고리를 추가했습니다.

## 역할별 노출

| 역할 | 노출 방식 |
|---|---|
| 자녀앱 | `/child/convenience`에서 전체 편의 허브 확인 |
| 부모님앱 | 큰 글씨로 오늘 챙길 것과 병원 접수 위치만 표시 |
| 매니저앱 | 병원 동선, 요청 서류, 현장 편의 체크를 표시 |
| 운영실 | `/ops/convenience`에서 준비물 누락, 서류 요청, 복약, 다음 예약 후보 관리 |

## 운영 원칙

편의 기능도 의료정보와 비용정보를 다룰 수 있으므로 다음 원칙을 지킵니다.

1. 처방전, 검사결과, 영수증은 동의 범위와 연결한다.
2. 병원 동선 데이터는 운영실이 수기 검증한 뒤 활성화한다.
3. 매니저가 의료적 판단을 하지 않도록 안내사항 전달과 관찰 기록으로 제한한다.
4. 가족 할 일은 담당자와 마감 시간을 반드시 남긴다.
5. 차량/이동 정책 문구는 편의 화면에서도 동일하게 유지한다.
