# STEP29 알림 큐

## 목적

카카오 알림톡, 문자, 앱 알림, 전화 콜백을 실제 연동하기 전에 알림 대기열을 만든다.

## 추가 기능

- 알림 템플릿
- 알림 대기열
- 식사·약 확인 필요 알림
- 비용 승인 요청 알림
- 매니저 배정 알림
- 부모님 만남 암호 알림
- 30초 요약 도착 알림
- 가족 공동조회 코드 알림
- 사회공헌 지원 검토 알림
- 운영실 알림 큐
- 발송 완료/실패/재대기 상태 관리

## 화면

- /care-notifications
- /child/notifications
- /ops/notifications

## 운영 원칙

- 실제 카카오 알림톡/SMS 연동은 배포 직전에 붙인다.
- 지금은 무엇을 누구에게 언제 보낼지 저장하는 큐를 먼저 만든다.
- 긴급 알림은 전화 확인으로 전환할 수 있어야 한다.
- 40대 이상 보호자가 이해하기 쉬운 제목과 문구를 사용한다.
