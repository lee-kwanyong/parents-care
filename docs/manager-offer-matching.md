# 매니저 알림·수락형 자동매칭

## 목적

운영실이 직접 배치만 하는 방식에서 벗어나, 검증된 매니저에게 케어 요청을 제안하고 매니저가 수락하는 구조를 만든다.

## 운영 흐름

1. 보호자 걱정 접수
2. 운영실이 케어 요청으로 정리
3. 최근 접수로 매칭 요청 생성
4. 조건에 맞는 검증 매니저에게 알림 발송
5. 매니저가 /manager/offers 에서 수락 또는 거절
6. 운영실이 /ops/manager-offers 에서 수락 매니저 배정 확정
7. manager_field_assignments 생성

## 안전 원칙

- 본인확인 완료 매니저만 제안 가능
- 활동 중 매니저만 제안 가능
- 직접 유상운송 포함 매니저 제외
- 수락 후에도 운영실 최종 확정 필요
- 추후 신뢰도 높은 매니저는 자동확정 가능
