# STEP23 추가비용 사전승인 + 결제 전 안전장치

## 목적

40대 이상 보호자는 비용이 불명확하면 불안해한다.
택시비, 서류 발급비, 식사 배송비, 추가 동행시간 등은 보호자 승인 후 진행해야 한다.

## 추가 기능

- 추가비용 사전승인 요청
- 비용 항목 관리
- 보호자 승인
- 보호자 거절
- 승인 전 결제 완료 방지
- 결제 대기
- 결제 완료
- 가족 할 일 자동 생성
- 운영실 비용 보드

## 화면

- /care-costs
- /child/costs
- /ops/costs

## 원칙

- 추가 비용은 보호자 승인 후 진행한다.
- 차량 보유와 직접 운송은 분리한다.
- 실제 PG 결제 연동은 배포 직전에 붙인다.
- 지금은 사전승인과 결제 전 안전장치를 먼저 만든다.
