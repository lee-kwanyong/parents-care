# 500가구 지자체 실증 모델 초안

## 목표

지자체 1곳 또는 광역 내 수행기관 2~3곳과 연계하여 ICT 안부확인·IoT 스마트 실버 케어 플랫폼의 현장 수용성과 성과지표를 검증한다.

## 실증 규모

- 총 500가구 권장 모델
- A그룹 고위험 취약노인: 150가구
- B그룹 일반관리 노인: 350가구

## 단계적 축소 MVP

초기 제안은 100가구 MVP로 시작한다.

- A그룹 30가구
- B그룹 70가구
- 기간 3~6개월
- 성과 확인 후 200~500가구 확장

## A그룹

- 만 75세 이상
- 독거 또는 거동 불편
- 미응답·도움 요청·몸 불편 신호 반복
- UWB 비접촉 센서 우선 적용 후보

## B그룹

- 만 65세 이상
- 노인맞춤돌봄서비스 수혜 가능 대상
- 만성질환·복약 관리 필요
- 스마트 복약통 우선 적용 후보

## 성과지표

- 일평균 응답률
- 식사 확인률
- 복약 확인률
- 미응답 발생 건수
- 도움 요청 감지 건수
- 가족 확인 완료율
- 수행기관 확인 완료율
- 사례관리 기록 건수
- 월간 성과보고 생성 여부
