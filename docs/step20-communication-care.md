# STEP20 사전 안심전화·30초 요약·운영실 연락 템플릿

## 목적

40대 이상 보호자는 복잡한 앱보다 전화와 짧은 요약을 선호할 수 있다.
부모님도 처음 보는 매니저나 서비스가 낯설 수 있으므로 사전 안심전화가 필요하다.

## 추가 기능

- 사전 안심전화
- 케어플랜 설명 전화
- 식사 확인 전화
- 복약 확인 전화
- 퇴원 후 확인 전화
- 사회공헌 안내 전화
- 긴급 콜백
- 30초 요약 리포트
- 운영실 연락 템플릿
- 부재중/재연락/완료 상태 관리

## 화면

- /care-comfort
- /child/summaries
- /ops/contact-center

## 40대 이상 UX 원칙

- 긴 리포트보다 30초 요약을 먼저 보여준다.
- 앱을 못 써도 전화로 설명받을 수 있게 한다.
- 부모님에게는 관리가 아니라 도움으로 표현한다.
- 운영실은 연락 템플릿으로 일관된 안내를 한다.
