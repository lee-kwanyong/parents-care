# STEP17 퇴원 후 7일 안심팩

## 목적

퇴원 직후 7일 동안 가족이 가장 걱정하는 약, 식사, 통증, 컨디션, 다음 외래, 낙상 위험을 확인한다.

## 추가 기능

- 퇴원 후 7일 안심팩 등록
- 1일차~7일차 체크 자동 생성
- 약 복용 확인
- 식사 가능 여부 확인
- 통증·컨디션 확인
- 다음 외래 확인
- 낙상 위험 확인
- 주의 필요 시 가족 할 일 자동 생성
- 자녀앱 안심판
- 운영실 관제

## 화면

- /care-discharge
- /child/discharge
- /ops/discharge

## 40대 이상 UX 원칙

- 가족에게는 “안심 / 확인 필요”를 먼저 보여준다.
- 7일 체크는 자동으로 만들어준다.
- 가족이 직접 복잡한 일정을 만들지 않게 한다.
- 부모님 상태가 나쁘면 가족 할 일로 연결한다.
