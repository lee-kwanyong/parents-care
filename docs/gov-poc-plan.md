# 지자체 실증 PoC 계획서 v1

## 실증 목표

안부웍스 플랫폼을 통해 고령자의 식사, 복약, 몸 상태, 도움 요청 데이터를 수집하고 가족·수행기관·지자체가 함께 확인·조치하는 운영 흐름의 효과성을 검증한다.

## 실증 범위

- 대상자 100명 MVP
- 보호자 100명 이상
- 가족 초대 50명 이상
- 수행기관 담당자 5~10명
- 지자체 관리자 2~5명

## 실증 기간

- 준비 1개월
- 운영 3~6개월
- 평가 1개월

## 주요 절차

1. 지자체·수행기관 협의
2. 대상자 모집
3. 개인정보 및 공유 동의
4. 보호자 연결
5. 부모님 안부 입력
6. 자녀 리포트 확인
7. 가족 실행 보드 운영
8. 수행기관 사례관리
9. 지자체 월간 리포트 생성
10. 결과보고

## 성공 기준

- 안부 응답률 60% 이상
- 보호자 리포트 열람률 50% 이상
- 가족 실행 완료율 50% 이상
- 사례관리 기록 누적
- 지자체 월간 성과 리포트 생성 가능
