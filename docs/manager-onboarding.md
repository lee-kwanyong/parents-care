# 동행케어 매니저 등록센터

## 목적

부모님을 실제로 모시고 갈 분을 별도 등록·심사·승인하는 흐름을 만든다.

## 벤치마킹 반영

- 자격증과 경력 확인
- 활동 가능 지역 확인
- 면접/교육/CPR 확인
- 디지털 활용 능력 확인
- 차량 보유 여부 확인
- 차량 보유와 직접 운송 가능 여부 분리
- 운영실 승인 후 신뢰카드 생성

## 화면

- /manager/apply
- /ops/managers

## 원칙

- 지원자는 쉽게 입력한다.
- 운영실은 신중하게 심사한다.
- 보호자에게는 신뢰카드로 쉽게 보여준다.
- 차량 보유는 참고 정보다.
- 매니저 개인차량 직접 유상운송은 기본 서비스에 포함하지 않는다.
