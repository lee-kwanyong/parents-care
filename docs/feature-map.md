# 기능 맵

## 보호자 기능

- 병원 일정 등록
- 케어 프로필 입력
- 가족 공동조회 코드
- 가족별 권한 설정
- 매니저 신뢰정보 확인
- 이동 방식 확인
- 타임라인 확인
- 소통함
- 리포트 확인
- 다음 액션 관리
- 결제/영수증 확인
- 평가 제출

## 부모님 기능

- 큰 글씨 오늘 일정
- 만남 암호
- 매니저 확인
- 동행 동의
- 공유범위 선택
- 긴급 연락
- 불편함 바로 알리기
- 음성 안내
- 자녀 전화
- 진행상황 확인

## 매니저 기능

- 지원서 작성
- 차량 보유 여부 입력
- 경력/자격/가능지역/병원 전문성 입력
- 오늘 배정 일정
- 부모님 케어 프로필
- 현장 체크리스트
- 의사 질문 리스트
- 단계 업데이트
- 위험 보고
- 리포트 작성
- 첨부파일 업로드
- 가능시간 관리

## 운영실 기능

- 매니저 심사/승인
- 배정 추천
- 위험 플래그
- 상태 관리
- 운영 로그
- 리포트 품질 검토
- 알림 템플릿
- 정책 관리
- 평가/안심도 관리
- 결제/정산/환불 관리
