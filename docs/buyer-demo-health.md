# STEP33 바이어 데모 헬스체크

## 목적

M&A 또는 전략제휴 담당자에게 실제로 작동하는 MVP를 보여준다.

## 추가 화면

- /buyer-demo

## 추가 API

- /api/demo/health

## 확인 대상

- 사진·카톡 접수
- 파일 메타데이터
- 케어패스포트
- 매니저 지원서
- 매니저 본인확인·신분확인
- 매니저 신뢰카드
- 검증 매니저 매칭 요청
- 검증 매니저 후보
- 현장 배정
- 현장 체크리스트
- 매니저 리포트
- 매칭 후 평가
- 알림 큐
- care-files Storage bucket

## 바이어 시연 순서

1. /buyer-demo에서 상태 확인
2. 데이터 부족 시 데모 데이터 생성
3. 보호자 화면
4. 운영실 접수함
5. 매니저 검증
6. 검증 매니저 매칭
7. 부모님 큰 글씨 화면
8. 리포트와 평가 확인

## 바이어에게 전달할 핵심 문장

이 데모는 전국 운영 전 단계의 MVP입니다.
보호자 걱정 접수, 운영실 정리, 검증 매니저 매칭, 부모님 화면, 리포트, 평가가 실제 DB에 저장되고 화면에서 확인됩니다.
