# STEP11 부모님 케어패스포트 고도화

## 목적

부모님 케어 플랫폼은 사람을 단순 연결하는 앱이 아니다. 부모님 상태를 알고 들어가야 케어 품질이 높아진다.

## 이번 단계에 추가한 정보

- 오른쪽 귀가 잘 안 들림
- 왼쪽 귀가 잘 안 들림
- 오른쪽 다리 통증
- 왼쪽 다리 통증
- 무릎, 허리, 어깨 통증
- 보행 불편
- 시력 불편
- 낙상 위험
- 알러지 유무
- 복용 중인 약
- 식사 제한
- 응대 방식
- 긴급 메모

## 40대 이상 보호자 UX

- 모르면 비워둘 수 있다.
- 질문은 크게 5묶음으로 나눈다.
- 저장 전 오늘의 안심판을 바로 보여준다.
- 가족 확인 질문은 3개 이하로 줄인다.
- 매니저 현장 주의사항은 자동으로 만든다.

## 다음 연결 대상

- 케어플랜 생성 시 케어패스포트 자동 반영
- 매니저앱 현장 체크리스트에 주의사항 표시
- 부모님 큰 글씨 화면에 부담 없는 문구 표시
- 안심밥상 식단 조건 반영
- 복약 확인 흐름에 복용약 메모 반영
