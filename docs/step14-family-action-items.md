# STEP14 가족 할 일 자동 생성

## 목적

부모님 케어 플랫폼은 리포트만 보내고 끝나면 안 된다.
가족이 실제로 해야 할 일을 쉽게 나누고 완료할 수 있어야 한다.

## 추가 기능

- 식사 미확인 → 가족 할 일 자동 생성
- 약 미확인 → 가족 할 일 자동 생성
- 도움 요청 → 긴급 가족 할 일 생성
- 케어플랜 가족 액션 → 가족 할 일 생성
- 담당자 지정
- 완료 처리
- 다른 가족에게 넘기기
- 운영실 가족 할 일 보드

## 화면

- /child/tasks
- /ops/tasks

## 40대 이상 UX 원칙

- 가족 할 일은 3개 이하로 먼저 보여준다.
- 버튼은 “제가 할게요”, “완료했어요”, “다른 가족에게 넘기기”처럼 일상 언어로 쓴다.
- 어려운 업무관리 용어를 쓰지 않는다.
- 앱을 못 쓰는 사용자는 운영실이 대신 담당자를 정할 수 있다.
