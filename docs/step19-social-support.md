# STEP19 사회공헌·공공지원 연결

## 목적

부모님 케어 플랫폼은 단순 유료 병원동행 앱이 아니다.
비용 부담, 결식 우려, 독거, 가족 부재, 퇴원 후 돌봄 공백이 있을 때 공공지원과 후원 연결을 검토해야 한다.

## 추가 기능

- 사회공헌 지원 요청
- 비용 부담 체크
- 식사 공백 체크
- 가족 부재 체크
- 퇴원 후 돌봄 공백 체크
- 지원 프로그램 추천
- 공공지원 서비스 안내
- 후원형 케어 쿠폰
- 무료 안부 확인 캠페인
- 식사 지원 연결
- 운영실 검토/연결 상태 관리
- 가족 할 일 자동 생성

## 40대 이상 UX 원칙

- “사회공헌 신청서”가 아니라 “비용이나 돌봄 공백이 걱정돼요”에서 시작한다.
- 사용자가 제도명을 몰라도 요청할 수 있어야 한다.
- 운영실이 공공지원, 후원 쿠폰, 식사 지원, 안부 확인 가능성을 정리한다.
- 가족에게는 검토 중 / 지원 가능 / 연결 완료만 쉽게 보여준다.
