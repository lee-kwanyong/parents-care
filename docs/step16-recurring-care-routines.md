# STEP16 정기진료·다음 예약 자동관리

## 목적

부모님 케어는 한 번으로 끝나지 않는다.
반복되는 진료와 다음 예약을 놓치지 않게 관리한다.

## 추가 기능

- 정기진료 등록
- 반복 주기 설정
- 다음 예약 후보 자동 생성
- 가족 할 일 자동 생성
- 자녀앱 다음 예약 확인
- 운영실 예약 요청/예약 완료 상태 관리

## 화면

- /care-routines
- /child/routines
- /ops/routines

## 40대 이상 UX 원칙

- 진료 주기는 쉬운 말로 선택한다.
- 다음 예약 후보는 앱이 먼저 만들어준다.
- 가족은 “예약을 맡길까요?” 수준으로만 확인한다.
- 운영실은 세부 상태를 관리한다.
