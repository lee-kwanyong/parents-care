# STEP25 통합 오늘의 안심판

## 목적

지금까지 만든 기능을 자녀앱 첫 화면에서 하나로 합친다.

40대 이상 보호자는 기능 메뉴를 찾아다니면 안 된다.
오늘 부모님 상태가 안심인지, 확인 필요인지, 긴급인지 먼저 봐야 한다.

## 통합 대상

- 통합 케어 케이스
- 걱정 접수
- 사진·카톡 접수
- 케어패스포트
- 밥·약·컨디션 확인
- 가족 할 일
- 서류·영수증
- 정기진료
- 다음 예약
- 퇴원 후 7일
- 안심밥상
- 사회공헌
- 연락센터
- 30초 요약
- 매니저 현장
- 비용 승인

## 화면

- /child
- /child/today
- /ops/today

## UX 원칙

- 자녀앱 홈은 기능 나열이 아니라 오늘 상태를 먼저 보여준다.
- 상태는 안심 / 확인 필요 / 긴급 3개만 쓴다.
- 가족 할 일은 3개 이하로 먼저 보여준다.
- 자세한 기능은 필요할 때만 들어가게 한다.
