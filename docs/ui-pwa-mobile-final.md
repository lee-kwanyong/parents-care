# UI PWA Mobile Final

## 목적

부모님 케어 플랫폼을 모바일/PWA 기준으로 정리한다.

## 추가된 것

- PWA manifest
- Service Worker
- Offline 안내 화면
- 자녀용 설치 안내
- 부모님용 설치 안내
- 모바일 최종 점검 화면
- AppFrame에서 Service Worker 등록
- 부모님 큰 글씨 화면에서 설치 안내 연결

## 화면

- /install
- /parent/install
- /mobile-check
- /offline

## 최종 기준

- 40대 이상 보호자가 첫 화면에서 이해해야 한다.
- 핵심 행동은 3번 안에 끝나야 한다.
- 전화·카톡·사진으로 대체 가능해야 한다.
- 부모님 화면은 큰 글씨와 큰 버튼만 있어야 한다.
- 검증된 매니저만 부모님 케어에 배정되어야 한다.
- PWA 설치는 “앱 설치”보다 “홈 화면에 큰 버튼 추가”로 설명한다.
