# 공동 케어룸 제품 방향

## 한 줄 정의

부모님 안심동행 케어는 역할별 앱을 따로 만드는 서비스가 아니라, `한 병원 일정 = 하나의 케어룸`으로 운영되는 병원동행 케어 운영 OS입니다.

## 왜 케어룸인가

병원동행은 예약만으로 끝나지 않습니다. 실제 이용자는 서로 다른 불안을 갖고 있습니다.

- 보호자는 지금 부모님이 괜찮은지, 다음에 무엇을 해야 하는지 궁금합니다.
- 부모님/환자는 오늘 누구를 어디서 만나면 되는지, 낯선 사람이 맞는지 확인하고 싶습니다.
- 동행매니저는 현장에서 실수하지 않도록 순서와 체크리스트가 필요합니다.
- 운영실은 위험 플래그, 동의, 정책, 리포트 품질, 정산을 관리해야 합니다.

그래서 모든 기능은 `appointment_id`를 중심으로 케어룸에 모읍니다.

## 케어룸에 들어가는 모듈

1. 일정 정보
2. 만남 암호
3. 매니저 신뢰정보
4. 부모님 케어 프로필
5. 가족 공동조회와 권한
6. 동행 동의와 공유범위
7. 진행상황 타임라인
8. 가족·매니저 소통함
9. 현장 체크리스트
10. 의사 질문 리스트
11. 위험상황 빠른 보고
12. 보호자 리포트
13. 보호자 다음 액션
14. 문서함과 영수증
15. 결제/정산 상태
16. 매니저 평가와 안심도 반영

## 역할별 화면 원칙

### 보호자

- 지금 상황을 첫 화면에 보여줍니다.
- 리포트는 요약과 상세를 나눕니다.
- 다음 액션은 체크리스트처럼 보여줍니다.
- 형제자매 공동조회는 가능하지만 민감정보 권한은 나눕니다.

### 부모님/환자

- 큰 글씨와 큰 버튼을 기본으로 합니다.
- 한 화면에 한 행동만 둡니다.
- 만남 암호, 매니저 이름/사진, 긴급 연락을 가장 크게 보여줍니다.
- 앱 사용이 어려운 사용자를 위해 전화 우선 모드를 둡니다.

### 동행매니저

- 오늘 일정과 다음 단계가 바로 보여야 합니다.
- 부모님 케어 프로필을 현장용으로 짧게 보여줍니다.
- 병원별 접수/검사/약국 가이드를 제공합니다.
- 리포트는 템플릿으로 작성하게 해서 품질을 일정하게 유지합니다.

### 운영실

- 매니저 배정은 지역, 병원 경험, 평점, 가능 시간, 위험 플래그를 함께 봅니다.
- 차량 보유 정보와 직접 운송 가능 여부는 반드시 분리합니다.
- 동의 누락, 보호자 연락 불가, 컨디션 이상, 지연은 별도 위험 플래그로 관리합니다.
- 리포트 품질과 평가를 매니저 안심도에 반영합니다.

## 개발 우선순위

1. 케어룸 상세 페이지를 `appointment_id` 기준으로 데이터 연결
2. 일정 등록과 가족 권한 연결
3. 부모님 큰 글씨 화면 연결
4. 매니저 단계 업데이트와 체크리스트 연결
5. 보호자 리포트와 다음 액션 연결
6. 위험 플래그와 운영실 큐 연결
7. 문서함, 알림, 결제, 정산 연결
