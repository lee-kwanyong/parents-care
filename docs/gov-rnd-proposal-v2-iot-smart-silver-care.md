# 지자체 R&D 제안서 v2 · IoT 스마트 실버 케어

## 제안명

안부지문 기반 고령자 생활리듬 변화감지 및 IoT 스마트 실버 케어 통합돌봄 플랫폼 개발·실증

## 제안 방향

안부웍스는 기존 parents-care.net 기반 부모님 안부 입력, 자녀 리포트, 가족 실행 보드, 지자체 운영실을 출발점으로 한다. 여기에 스마트 복약통과 UWB 비접촉 센서 이벤트를 단계적으로 연동하여 지자체가 운영 가능한 ICT 안부확인·통합돌봄 관제 플랫폼으로 고도화한다.

## 핵심 문제

- 전화·방문 중심 안부확인의 행정 부담
- 식사·복약·몸 상태 변화의 데이터 부재
- 가족·수행기관·지자체 간 조치 이력 분산
- 기존 센서·전화 중심 스마트돌봄의 오경보, 거부감, 형식적 응대 한계
- 지자체 성과보고 자동화 부재

## 핵심 솔루션

1. 부모님 PWA 안부 입력
2. 자녀·가족 안부지문 리포트
3. 가족 실행 보드
4. 지자체 실증 운영실
5. 스마트 복약통 이벤트 연동
6. UWB 비접촉 센서 이벤트 연동
7. 월간 성과보고 및 감사로그

## 단계별 실증 전략

### 1단계: 소프트웨어 MVP 실증

- 대상: 100가구
- 기능: 부모님 안부 입력, 자녀 리포트, 가족 실행 보드, 지자체 운영실
- 목표: 응답률, 복약 확인률, 식사 확인률, 가족 확인 완료율 검증

### 2단계: 스마트 복약통 연동

- 대상: 일반관리군 중심
- 기능: 약통 개폐 로그, 예정 시간 초과 미개봉, 복약 미확인 알림
- 목표: 복약 이행 데이터 자동화 가능성 검증

### 3단계: UWB 비접촉 센서 연동

- 대상: 고위험군 중심
- 기능: 재실·부재, 무활동, 낙상 의심, 호흡 저하 의심 이벤트
- 목표: 영상·음성 없는 비접촉 관제 수용성 및 정확도 검증

### 4단계: 조달·성과보고 패키지

- 월간 성과 리포트
- 사례관리 기록
- 감사로그
- CSV/PDF 내보내기
- 지자체 R&D 후속 제안

## 제안서 핵심 문장

본 과제는 고령자의 식사·복약·몸 상태·도움 요청 선택 데이터와 스마트 복약통·UWB 비접촉 센서 이벤트를 통합하여, 가족·수행기관·지자체가 위험 신호를 함께 확인·조치·보고할 수 있는 ICT 기반 지역사회 통합돌봄 모니터링 플랫폼을 개발·실증하는 것을 목표로 한다.
