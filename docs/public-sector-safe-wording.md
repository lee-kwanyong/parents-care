# 공공 제안서 표현 보정 가이드

## 원칙

정부·지자체 제안서는 확정·보장형 표현보다 목표·검증·연계 가능성 중심으로 작성한다.

## 표현 보정

| 위험한 표현 | 제안서용 표현 |
|---|---|
| 오탐률 2% 미만 보장 | 오탐률 2% 미만을 목표로 실증 데이터 기반 검증 |
| 원클릭 119 연계 | 응급안전망·119 연계 가능 구조 검토 |
| 데이터 유실 가능성 0% | 이중화 백업과 접속기록 보관을 통한 데이터 유실 최소화 |
| 무경쟁 수의계약 확보 | 실증 성과 기반 조달·혁신제품·디지털서비스 등록 가능성 검토 |
| 개인정보보호 완벽 대응 | 개인정보 최소수집, 동의관리, 접근권한, 감사로그 체계 구축 |
| 전국 243개 지자체 즉시 확산 | 실증 성과 확보 후 단계적 지자체 확산 |

## 권장 문장

본 플랫폼은 기존 전화·방문 중심 안부확인의 한계를 보완하여, 고령자의 식사·복약·몸 상태·도움 요청 및 IoT 이벤트를 기반으로 생활리듬 변화와 돌봄 필요 신호를 조기에 포착하고, 가족 및 수행기관의 조치 이력을 행정 보고 가능한 데이터로 전환한다.
