# STEP15 보험서류·영수증 챙김팩

## 목적

병원 다녀온 뒤 자녀가 자주 놓치는 서류를 쉽게 챙긴다.

## 포함 서류

- 진료비 영수증
- 진료비 세부내역서
- 처방전 사본
- 통원확인서
- 검사결과지
- 진단서/소견서
- 잘 모르겠어요, 필요한 서류 추천해주세요

## 흐름

1. 보호자가 필요한 서류를 선택한다.
2. 모르면 “필요한 서류 추천해주세요”를 누른다.
3. 기본 보험서류 묶음으로 요청이 생성된다.
4. 가족 할 일이 자동 생성된다.
5. 운영실은 준비/수령/전달 상태를 관리한다.

## 화면

- /care-documents
- /child/documents
- /ops/documents

## 40대 이상 UX 원칙

- 서류명을 몰라도 요청할 수 있어야 한다.
- “잘 모르겠어요” 버튼이 있어야 한다.
- 가족에게는 수령 여부와 전달 여부만 쉽게 보여준다.
- 운영실은 세부 상태를 관리한다.
