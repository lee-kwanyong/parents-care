# STEP27 가족 공동조회 코드 + 가족 역할/담당자 구조

## 목적

부모님 케어는 한 명의 자녀만 보는 구조로는 부족하다.
형제자매, 배우자, 친척, 돌봄 담당자가 함께 확인하고 역할을 나눠야 한다.

## 추가 기능

- 가족 공간 생성
- 가족 공동조회 코드 발급
- 초대 코드로 가족 참여
- 가족 역할 설정
- 조회 권한 설정
- 비용 승인자 지정
- 가족 할 일 담당자 지정
- 가족 참여 기록
- 운영실 가족 공동조회 보드

## 권한 구조

- 전체 보기
- 요약 보기
- 할 일만 보기
- 긴급만 받기
- 비용 승인 가능
- 가족 초대 가능

## 화면

- /family-code
- /child/family
- /ops/families

## UX 원칙

- 가족 초대는 코드 하나로 끝낸다.
- 역할명은 쉬운 말로 쓴다.
- 비용 승인과 가족 할 일 담당자는 명확히 분리한다.
- 로그인 연동은 배포 직전에 휴대폰/카카오 인증과 연결한다.
