# UI Core Flows

## 목적

핵심 사용자 흐름을 40대 이상 보호자 기준으로 정리한다.

## 변경 화면

- /care-request
- /care-intake
- /child/tasks
- /child/cases

## 기준

- 걱정 선택부터 시작
- 사진·카톡·전화 대체 가능
- 3단계 안에 접수
- 큰 버튼
- 모바일 우선
- 가족 할 일은 쉬운 문장 사용
- 케이스는 안심 / 확인 필요 / 긴급 먼저 표시
