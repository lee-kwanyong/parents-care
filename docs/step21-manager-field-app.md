# STEP21 동행매니저 현장앱 고도화

## 목적

운영실이 만든 케어플랜이 현장에서 실수 없이 실행되도록 매니저앱을 고도화한다.

## 추가 기능

- 오늘 배정 일정
- 만남 암호 확인
- 차량 보유/직접 운송 분리 안내
- 케어패스포트 현장 주의사항
- 청력/통증/낙상/알러지/복용약 확인
- 병원 접수/진료/약국/서류 체크
- 식사/컨디션 확인
- 안전 귀가 확인
- 단계별 진행상태 업데이트
- 보호자 리포트 초안 작성
- 운영실 매니저 현장 보드

## 차량 정책

차량 보유 여부는 참고 정보다.
매니저 개인차량 직접 유상운송은 기본 서비스에 포함하지 않는다.
기본 이동은 병원 앞 만남, 집 앞 만남 후 택시 동행, 이동지원 제휴 기준이다.

## 40대 이상 UX 원칙과의 연결

보호자 화면은 단순해야 한다.
복잡한 체크는 운영실과 매니저앱이 대신 처리한다.
가족에게는 안심/확인 필요/긴급, 가족 할 일, 30초 요약만 보여준다.
