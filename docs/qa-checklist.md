# QA 체크리스트

## 자녀앱

- 일정 등록 시 차량 정책 확인 체크 없이는 저장되지 않는가?
- 가족 공동조회 코드가 만료/사용 처리되는가?
- 매니저 신뢰카드에 차량 보유와 직접 운송 가능 여부가 분리 표시되는가?
- 리포트가 운영실 검수 전에는 발송 완료로 보이지 않는가?
- 평가 4개 항목이 모두 저장되는가?

## 부모님앱

- 360px 폭에서도 만남 암호와 전화 버튼이 잘 보이는가?
- 긴급 버튼이 항상 큰 영역으로 노출되는가?
- 공유 범위 선택 문구가 쉬운가?
- 오늘 일정 외 과도한 정보가 노출되지 않는가?

## 매니저앱

- 체크리스트를 누락해도 리포트 제출 전에 확인되는가?
- 진행상태 업데이트가 timeline_events에 기록되는가?
- 보호자 질문 리스트가 진료 전 화면에 보이는가?
- 리포트 초안이 submitted 상태로 운영실에 넘어가는가?

## 운영실

- 직접 운송 요청이 들어오면 risk_flags가 생성되는가?
- 리포트 품질 게이트를 통과하지 않으면 발송되지 않는가?
- 미해결 위험 플래그가 있는 매니저는 배정 추천에서 감점되는가?
- 운영 로그에 누가 언제 어떤 조치를 했는지 남는가?


## 안심 체크인/SLA

- 만남 암호가 일치해야 handoff 체크포인트가 완료되는가?
- 암호 불일치가 반복되면 risk_flags와 safety_escalations가 생성되는가?
- 각 safety checkpoint가 expected_at + grace time을 넘기면 운영실 점검 대상이 되는가?
- 안전 종료 확인 전에는 일정이 완전히 닫힌 것으로 보이지 않는가?
- 부모님앱에서는 “집에 잘 도착했어요” 같은 큰 버튼으로만 안전 종료를 확인할 수 있는가?
- 대체 배정 playbook이 운영실 리스크 보드에서 보이는가?
