# 부모님 안심동행 케어 제품 방향성

## 한 문장 정의

보호자, 부모님, 동행매니저, 운영실이 같은 병원동행 일정을 각자 필요한 방식으로 보는 **병원동행 운영 OS**입니다.

## 핵심 사용자별 목표

### 보호자 / 자녀

보호자는 병원에 직접 가지 못하는 불안이 큽니다. 그래서 보호자앱은 기능보다 “안심”이 먼저입니다.

필수 기능:

- 병원 일정 등록
- 가족 공동조회와 권한 설정
- 부모님 케어 프로필 입력
- 매니저 신뢰정보 확인
- 이동 방식 확인
- 오늘 진행 타임라인 확인
- 가족·매니저 소통함
- 보호자 리포트 확인
- 보호자가 해야 할 다음 액션 자동 정리
- 결제/영수증/실비 기록
- 매니저 평가

### 부모님 / 환자

부모님앱은 앱 사용을 잘하는 사람이 아니라도 편해야 합니다. 읽고 이해하는 화면보다, 큰 버튼과 짧은 문장이 중요합니다.

필수 기능:

- 큰 글씨 오늘 일정
- 만나는 매니저 이름/사진/안심도
- 만남 암호
- 병원동행 동의
- 자녀에게 공유할 범위 선택
- 긴급 연락 버튼
- 진행상황 확인
- 불편한 점 바로 알리기
- 음성 안내 / 글씨 크게 / 전화 버튼

### 동행매니저

매니저는 현장에서 실수하지 않는 것이 중요합니다. 그래서 매니저앱은 순서와 체크리스트가 중심입니다.

필수 기능:

- 매니저 지원서
- 차량 보유 여부 입력
- 경력/자격/가능지역/병원 전문성 입력
- 오늘 배정 일정 확인
- 부모님 케어 프로필 확인
- 현장 체크리스트
- 의사에게 확인할 질문 리스트
- 단계별 진행상태 업데이트
- 위험상황 빠른 보고
- 보호자 리포트 작성
- 사진/영수증/처방전 첨부

### 운영실

운영실은 매칭, 리스크, 품질, 정책을 관리합니다.

필수 기능:

- 매니저 심사/승인
- 매니저 배정 추천
- 위험 플래그 확인
- 차량/픽업 정책 확인
- 운영 로그
- 상태 관리
- 리포트/평가 관리
- 알림톡 템플릿 관리
- 정산/환불 관리
- 매니저 교육/재심사 큐

## 모두에게 필요한 공통 기능

1. **동의와 공유범위**
   - 동행 동의
   - 민감정보 처리 동의
   - 위치공유 동의
   - 리포트 공유 범위
   - 가족별 권한

2. **안심 확인 장치**
   - 만남 암호
   - 매니저 신뢰정보
   - 단계별 진행상황
   - 긴급 연락
   - 운영실 위험 플래그

3. **케어 프로필**
   - 보행 상태
   - 청력/시력/의사소통 방식
   - 복약 주의사항
   - 알레르기/주의사항
   - 오래 서 있기 어려움 등 현장 메모

4. **다음 액션 자동화**
   - 약 복용 확인
   - 다음 예약 등록
   - 검사 결과 확인
   - 보험서류 요청
   - 가족에게 역할 배정

5. **품질과 신뢰도**
   - 평가가 매니저 안심도에 반영
   - 낮은 평가와 위험 플래그는 운영실 검토
   - 리포트 품질 체크리스트
   - 병원별 예상 소요시간과 전문 매니저 풀

## 차량/이동 정책

차량 보유 여부는 신뢰정보로 표시할 수 있지만, 직접 운송 가능과 같은 뜻으로 쓰지 않습니다.

기본 이동 방식:

- 병원 앞 만남
- 집 앞 만남 후 택시 동행
- 이동지원 제휴 연결

분리해야 하는 항목:

- 매니저 차량 보유 여부
- 운송 자격/계약/보험이 확인된 제휴 운송 서비스
- 병원동행 서비스 자체 비용
- 택시비/실비/수납비

## MVP에서 바로 개발할 기능

1. 로그인과 역할 분리
2. 가족 생성과 공동조회 코드
3. 부모님 케어 프로필
4. 병원 일정 등록
5. 운영실 매니저 배정
6. 부모님 큰 글씨 화면과 만남 암호
7. 매니저 현장 체크리스트
8. 진행상태 업데이트
9. 보호자 리포트
10. 보호자 다음 액션
11. 평가와 안심도 반영
