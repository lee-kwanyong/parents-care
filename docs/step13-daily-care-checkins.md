# STEP13 식사·복약·컨디션 확인

## 목적

부모님 큰 글씨 화면에서 누른 버튼이 자녀앱과 운영실에 바로 반영되게 한다.

## 추가 기능

- 점심 먹었어요
- 아직 안 먹었어요
- 약 먹었어요
- 약 아직 안 먹었어요
- 컨디션 괜찮아요
- 도움이 필요해요
- 집에 잘 도착했어요

## 연결 화면

- /parent/today
- /child/daily-care
- /ops/daily-care

## UX 원칙

- 부모님은 복잡한 메뉴 없이 큰 버튼만 누른다.
- 자녀는 안심/확인 필요/긴급만 먼저 본다.
- 운영실은 도움 요청, 식사 미확인, 약 미확인을 우선 확인한다.
- 모바일 UI 정리는 마지막 단계에서 별도로 진행한다.
