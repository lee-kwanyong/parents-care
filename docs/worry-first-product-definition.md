# 부모님 걱정 해결 앱 · 제품 재정의

## 최종 정의

**부모님 케어 플랫폼**은 병원동행 예약앱이 아니라, 40대 이상 자녀가 부모님 걱정을 쉽게 맡기면 병원·식사·약·퇴원 후 케어·서류·정기진료·안부를 해결 플랜으로 정리해주는 서비스입니다.

## 반드시 기억할 사용자

- 핵심 사용자는 40대 이상 자녀입니다.
- 조금만 어렵고 복잡하면 이탈합니다.
- 그래서 기능은 많아도 첫 화면과 핵심 행동은 단순해야 합니다.
- 부모님 화면은 앱이 아니라 큰 글씨와 큰 버튼이어야 합니다.

## UX 원칙

1. 기능명이 아니라 걱정 선택으로 시작합니다.
2. 핵심 행동은 3번 안에 끝납니다.
3. 전화, 카톡, 사진, 직접입력 중 편한 방식으로 맡길 수 있습니다.
4. 자녀는 긴 리포트보다 안심/확인 필요/긴급을 먼저 봅니다.
5. 부모님은 오늘 일정, 만남 암호, 자녀 전화, 도움 버튼만 봅니다.
6. 사회공헌 연결이 필요한 가정은 운영실이 공공지원/후원/지역 서비스를 안내합니다.

## 핵심 화면

```txt
/                       걱정 해결형 홈
/care-request           걱정 접수센터
/child                  40대 이상 자녀용 초간단 홈
/care-passport          부모님 케어패스포트
/care-meals             안심밥상, 식사 확인, 정기배송/회복식 연결
/impact                 사회공헌 레이어
/ops/requests           운영실 걱정 요청센터
```

## 차별화 문장

기존 병원동행은 병원에 같이 가주는 서비스입니다. 부모님 케어 플랫폼은 병원 가기 전 준비부터, 진료 후 약·식사·서류·다음 예약까지 가족 대신 정리하는 서비스입니다.
