# Android PWA + 케어파트너 알바형 매니저앱

## 방향

- 보호자앱: 부모님 걱정 접수
- 매니저앱: 검증 후 일감 수락/거절
- 운영실: 최초 검증과 품질 관리
- 부모님앱: 큰 글씨 일정 확인

## 매니저 흐름

1. /manager/apply 에서 3분 간단 등록
2. /manager/vetting 에서 검증자료 제출
3. /ops/manager-vetting 에서 운영실 확인
4. 검증 완료 후 /manager 에 일감 표시
5. 수락/거절
6. 오늘 배정 생성
7. 현장 시작/완료
8. /manager/earnings 에 정산 예정 반영

## Android 사용

- Android Chrome 기준
- /manager/install 에서 홈 화면 추가 안내
- 초기에는 PWA로 운영
- 이후 Google Play 등록용 래퍼 앱 검토

## 법적 주의

- 개인차량 직접 유상운송은 기본 서비스에 포함하지 않는다.
- 이동은 택시, 보호자 동의, 합법적 이동수단 기준으로 안내한다.
