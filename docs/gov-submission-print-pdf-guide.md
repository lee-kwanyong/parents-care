# 지자체 제출 패키지 PDF 저장 가이드

## 목적

/gov/submission 에서 생성한 R&D 제안서, 실증 운영계획서, KPI 매트릭스, 보안 체크리스트, 지자체 제안 메일을 하나의 인쇄본으로 묶어 지자체 제출용 PDF로 저장한다.

## 사용 경로

- /gov/submission
- /gov/submission/print

## 사용 순서

1. /gov/submission 접속
2. 과제명, 대상 지역, 실증 가구 수, 예산 입력
3. 문서 다시 생성
4. PDF 저장용 인쇄본 클릭
5. 브라우저 인쇄
6. 대상: PDF로 저장
7. 용지: A4
8. 여백: 기본 또는 없음
9. 배경 그래픽 표시 체크
10. 저장

## 포함 문서

- 표지
- R&D 제안서
- 실증 운영계획서
- KPI 매트릭스
- 개인정보·보안 체크리스트
- 지자체 제안 메일 초안

## 공공 제출 시 주의

- 보장형 표현은 목표·검증형 표현으로 변경
- 119 연계는 가능 구조 검토로 표현
- 조달 연계는 실증 성과 기반 가능성 검토로 표현
- 개인정보는 최소수집·동의·감사로그 체계 중심으로 설명
