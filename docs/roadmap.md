# 개발 로드맵

## Sprint 1: 제품 뼈대

- Next.js + Supabase 연결
- Auth 로그인
- 프로필/역할 생성
- 가족 생성
- 가족 공동조회 코드
- 기본 라우팅: 자녀앱, 부모님앱, 매니저앱, 운영실

## Sprint 2: 일정과 케어 프로필

- 부모님 케어 프로필 CRUD
- 병원 일정 CRUD
- 이동 방식 선택
- 의사 질문 리스트
- 부모님 공유범위 설정
- 일정별 동의 기록

## Sprint 3: 배정과 현장 진행

- 운영실 매니저 심사/승인
- 매니저 가능시간 입력
- 배정 추천 큐
- 매니저 배정
- 현장 체크리스트 생성
- 단계별 진행상태 업데이트
- Supabase Realtime으로 보호자/부모님 화면 갱신

## Sprint 4: 리포트와 다음 액션

- 보호자 리포트 작성
- 검사/약/다음 예약/컨디션 정리
- 보호자 다음 액션 생성
- 사진/영수증/처방전 첨부
- 가족 소통함
- 매니저 평가 제출
- 안심도 계산 로직

## Sprint 5: 운영 안정화

- 위험 플래그 자동 생성
- 응급/도움 요청 이벤트
- 운영 로그
- 리포트 품질 검토
- 정책 관리
- 알림톡 템플릿 설계
- 결제/정산 준비

## Sprint 6: 서비스 전환

- 알림톡 연동
- 전자서명 연동
- 결제 연동
- 위치공유 동의와 세션
- Vercel Production 배포
- 개인정보 처리방침/이용약관/동의서 정리
- 운영 매뉴얼 작성
