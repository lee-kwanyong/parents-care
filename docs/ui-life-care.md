# UI Life Care

## 목적

생활 케어 핵심 화면을 40대 이상 보호자 기준으로 정리한다.

## 변경 화면

- /care-passport
- /care-meals
- /care-discharge
- /care-costs

## 기준

- 케어패스포트는 현장 실수를 줄이는 정보만 받는다.
- 식사 케어는 “밥을 못 챙겨 드세요”에서 시작한다.
- 퇴원 후 7일은 약, 식사, 통증, 다음 외래, 낙상만 먼저 본다.
- 비용 승인은 보호자 승인 전 진행 불가 원칙을 강조한다.
- 차량 보유와 직접 운송 가능 여부는 계속 분리한다.
