# STEP18 안심밥상·식사 케어

## 목적

부모님 케어 플랫폼은 병원동행만으로 끝나면 안 된다.
혼자 계신 부모님, 퇴원 직후 부모님, 씹기 어려운 부모님, 당뇨·저염식이 필요한 부모님에게 식사 케어는 매일 필요한 걱정이다.

## 추가 기능

- 식사 확인만 하기
- 안심밥상 정기배송
- 퇴원 후 회복식 7일
- 식단 상담
- 공공·후원 식사 연결
- 저염식
- 당뇨식
- 죽·연화식
- 식사 체크 자동 생성
- 배송 완료/배송 실패
- 못 드셨어요/도움 필요
- 가족 할 일 자동 생성

## 40대 이상 UX 원칙

- “식사 서비스”가 아니라 “밥을 잘 못 챙겨 드세요”라는 걱정에서 시작한다.
- 잘 모르겠으면 식사 조건을 unknown으로 두고 운영실이 정리한다.
- 자녀는 안심/확인 필요/긴급만 먼저 본다.
- 운영실은 식사 미확인, 배송 실패, 사회공헌 요청을 우선 확인한다.
