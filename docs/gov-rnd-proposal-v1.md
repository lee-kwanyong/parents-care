# 안부지문 기반 지역사회 통합돌봄 모니터링 플랫폼 개발 및 실증 제안서 v1

## 1. 과제명

안부지문 기반 고령자 생활리듬 변화감지 및 지역사회 통합돌봄 실행지원 플랫폼 개발

## 2. 추진 배경

고령자의 안전·안부확인은 전화와 방문 중심으로 이루어져 담당자 업무 부담이 크고, 식사·복약·몸 상태 변화가 데이터로 누적되지 않아 사전 예방과 사례관리가 어렵다. 본 과제는 고령자의 일상 선택 데이터를 생활리듬 지표로 전환하여 가족, 수행기관, 지자체가 함께 확인·조치·보고할 수 있는 ICT 기반 통합돌봄 운영 플랫폼을 개발·실증한다.

## 3. 정책 부합성

- 스마트 사회서비스 시범사업: AI·ICT 기반 신규 사회서비스 모델 발굴 및 실증
- 지역사회 통합돌봄: 지자체 중심 신청·판정·계획·서비스 제공·모니터링
- 노인맞춤돌봄서비스: ICT 기반 안전·안부확인 보조
- 고독사 예방: 안부확인, 위험 조기 발견, 사회적 관계망·사후관리

## 4. 개발 목표

1. 부모님용 PWA 안부 입력 서비스
2. 자녀·가족용 안부지문 리포트
3. 가족 실행 보드
4. 수행기관 사례관리 화면
5. 지자체 실증 운영실
6. 월간 성과 리포트
7. 접근·처리 감사로그

## 5. 핵심 기술

- 안부지문 알고리즘
- 식사·복약·응답 시간 기반 생활리듬 변화감지
- 위험 신호 분류: 정상 / 주의 / 확인 필요
- 가족·기관 실행 이력 관리
- 지자체 성과지표 자동 집계

## 6. 실증 계획

- 대상자: 독거노인, 고령부부, 퇴원 후 관리 필요자, 복약 관리 필요자
- 규모: MVP 100명, 권장 200명
- 기간: 6개월~10개월
- 참여자: 부모님, 보호자, 다른 가족, 수행기관 담당자, 지자체 관리자
- 실증기관: 1개 시군구 또는 수행기관 2~3곳

## 7. 성과지표

- 일평균 안부 응답률
- 식사 확인률
- 복약 확인률
- 미응답 발생 건수
- 도움 요청 감지 건수
- 가족 확인 완료율
- 수행기관 확인 완료율
- 평균 확인 소요시간
- 사례관리 기록 건수
- 월간 보고서 생성 건수

## 8. 기대효과

- 전화·방문 중심 안부확인의 업무 부담 완화
- 식사·복약·몸 상태 변화의 데이터화
- 가족 참여형 사전 예방 돌봄 강화
- 지자체 모니터링과 성과보고 자동화
- 지역사회 통합돌봄 사후관리 체계 보완
