# STEP10 걱정 우선 UX 리셋

## 판단

기존 병원동행 운영 기능은 버리지 않는다. 다만 보호자가 처음 보는 화면으로 두면 안 된다.

## 제품 기준

- 보호자 첫 화면: 무엇이 걱정되세요?
- 자녀 화면: 오늘의 안심판
- 부모님 화면: 큰 글씨, 큰 버튼
- 운영실 화면: 걱정을 처리하는 내부 대시보드
- 병원동행은 여러 케어 중 하나일 뿐이다.
- 식사, 약, 서류, 퇴원 후 7일, 정기진료, 사회공헌이 같이 있어야 한다.

## 라우트 구조

/                  보호자 첫 화면
/child             자녀 간편 홈
/care-request      걱정 접수센터
/care-passport     부모님 상태 등록
/parent/today      부모님 큰 글씨 화면
/ops               운영실 대시보드
/ops/worry-center  걱정 요청 목록
/ops/plan-builder  케어플랜 생성
/ops/care-passport 케어패스포트 확인

## 40대 이상 UX 원칙

- 질문은 3개 이하
- 가족 할 일은 3개 이하
- 기능명이 아니라 걱정명으로 보여준다
- 전화/카톡/사진 접수는 항상 열어둔다
- 로그인은 배포 직전에 휴대폰/카카오 중심으로 연결한다
- 알러지와 복용약은 케어 전에 반드시 확인한다
