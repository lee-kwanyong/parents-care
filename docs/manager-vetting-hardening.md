# 최초 매니저 검증 시스템 강화

## 핵심 방향

요청마다 매니저를 다시 검증하지 않는다.
최초 채용 단계에서 검증을 견고하게 하고, 이후에는 검증 매니저 풀에서만 매칭한다.

## 필수 검증 항목

- 휴대폰 본인확인
- 신분 확인
- 요양보호사 또는 관련 자격증
- 병원동행 기본교육
- 응급상황 대응 교육
- 개인정보·병원정보 취급 동의
- 의료행위 금지 원칙 확인
- 이동·차량 정책 확인
- 운영실 면접
- 결격사유 확인 동의

## 운영 흐름

1. 매니저 지원
2. 검증 자료 제출
3. 운영실 확인/반려
4. 필수 항목 전체 확인
5. 최종 승인
6. 검증 매니저 풀 등록
7. 요청 발생 시 검증 매니저에게만 알림
