# 부모님 걱정해결 플랫폼 재정의

## 핵심 사용자

이 앱을 끝까지 기준 삼아야 하는 사용자는 40대 이상 보호자입니다. 이 사용자는 앱을 못 쓰는 사람이 아니라, 새 앱을 배울 여유가 적은 사람입니다. 조금만 어렵거나 입력이 길어지면 이탈할 가능성이 높습니다.

## 제품 정의

부모님 병원동행 앱이 아니라 부모님 케어 플랫폼입니다.

> 부모님 걱정을 접수해서 병원, 식사, 약, 서류, 퇴원 후 케어, 정기진료를 가족 대신 정리해주는 서비스

## 기존 병원동행/매칭 서비스와 다른 점

기존 서비스는 보통 사용자가 원하는 기능을 알고 들어온다고 가정합니다.

```txt
병원동행 신청
간병 신청
가사돌봄 신청
요양시설 찾기
```

우리 서비스는 사용자가 기능명을 모르는 상황을 전제로 합니다.

```txt
엄마가 혼자 있는데 어떡하지?
밥을 잘 못 드시는데 어떡하지?
약을 챙기는지 모르겠어.
퇴원했는데 집에서 괜찮을까?
내가 뭘 신청해야 하는지도 모르겠다.
```

그래서 첫 화면은 기능 메뉴가 아니라 걱정 메뉴가 됩니다.

## 반드시 포함하는 편리함

1. 걱정 접수센터
2. 잘 모르겠어요 버튼
3. 전화/카톡/사진 접수
4. 오늘의 안심판
5. 부모님 케어패스포트
6. 안심밥상
7. 복약 확인
8. 퇴원 후 7일 안심팩
9. 정기진료 자동관리
10. 보험서류/영수증 챙김
11. 사전 안심전화
12. 30초 음성 요약 리포트
13. 추가비용 사전승인
14. 같은 매니저 우선 배정
15. 가족 역할 자동 배분
16. 부모님 거부감 낮추는 문구
17. 사회공헌 케어

## UX 원칙

```txt
사용자는 기능을 고르지 않는다. 걱정을 누른다.
사용자는 내용을 길게 입력하지 않는다. 전화·카톡·사진으로 맡긴다.
사용자는 진행상황을 해석하지 않는다. 안심/확인 필요/긴급만 본다.
부모님은 앱을 배우지 않는다. 큰 버튼만 누른다.
운영실은 복잡해도 된다. 고객 화면은 단순해야 한다.
```

## 화면 우선순위

### 자녀앱

```txt
엄마, 오늘 괜찮으세요?
[걱정 맡기기]
[밥·약 확인]
[리포트 보기]
[퇴원 후 케어]
```

### 부모님앱

```txt
오늘 병원 가는 날이에요
만나는 사람
만남 암호
[자녀에게 전화]
[도움 필요]
[집에 잘 도착했어요]
```

### 운영실

```txt
걱정 접수
운영실 분류
케어 플랜 생성
보호자 확인
매니저/제휴/알림/리포트 실행
```
