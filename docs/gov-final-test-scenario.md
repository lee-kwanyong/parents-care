# 최종 시나리오 테스트 문서

## 시나리오 A: 부모님 안부 입력

1. /parent/login 접속
2. 6자리 코드 입력
3. 휴대폰 뒤 4자리 입력
4. /parent/today 진입
5. 아침 식사 선택
6. 아침약 선택
7. 몸 상태 선택
8. 저장 성공 메시지 확인

## 시나리오 B: 자녀 리포트

1. /child/dashboard 접속
2. 가족코드 입력
3. 오늘 식사·복약 표시 확인
4. 안부지문 점수 확인
5. 최근 14일 기록 확인

## 시나리오 C: 가족 실행 보드

1. /family/actions 접속
2. 권장 실행 추가
3. 내가 확인할게요 클릭
4. 확인 완료 클릭
5. 완료 기록 확인

## 시나리오 D: 지자체 운영실

1. /gov/dashboard 접속
2. 대상자 수 확인
3. 위험 대상자 확인
4. /gov/recipients에서 대상자 등록
5. /gov/cases에서 사례관리 등록
6. /gov/reports에서 성과보고 확인

## 시나리오 E: 제출 패키지

1. /gov/submission 접속
2. 과제명·지역·가구 수 입력
3. 문서 다시 생성
4. Markdown 다운로드
5. /gov/submission/print 접속
6. PDF 저장
