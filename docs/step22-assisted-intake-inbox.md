# STEP22 사진·카톡·문자 캡처로 맡기기 접수함

## 목적

40대 이상 보호자가 긴 폼을 쓰지 않고도 부모님 걱정을 맡길 수 있게 한다.

## 추가 기능

- 사진으로 맡기기
- 카톡 내용 붙여넣기
- 문자 캡처/붙여넣기
- 전화로 맡기기
- 서류 사진으로 맡기기
- 약 봉투, 영수증, 처방전, 예약증 첨부
- 자동 걱정 유형 추정
- 케어팩 추천
- 운영실 접수함
- 케어 요청으로 변환

## 화면

- /care-intake
- /child/intake-inbox
- /ops/intake-inbox

## 40대 이상 UX 원칙

- 사용자는 기능을 찾지 않고 사진이나 카톡으로 맡긴다.
- 앱이 어려우면 전화로 맡긴다.
- 운영실이 내용을 정리해 케어 요청으로 변환한다.
- 가족은 접수됨 / 정리 중 / 케어 요청 생성만 쉽게 본다.
