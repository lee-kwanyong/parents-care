# 부모님 케어 플랫폼

부모님 걱정을 쉽게 맡기는 부모님 케어 플랫폼입니다. 병원동행 앱이 아니라 병원, 밥, 약, 서류, 퇴원 후 케어, 정기진료, 사회공헌을 한 번에 정리합니다.

## 실행

```bash
npm install
cp .env.example .env.local
npm run dev
```

## 확인

```bash
npm run typecheck
npm run build
```

## 핵심 화면

- `/care-request` 걱정 접수센터
- `/care-packs` 케어팩
- `/care-passport` 부모님 케어패스포트
- `/care-meal` 안심밥상
- `/care-plans/discharge` 퇴원 후 7일 안심팩
- `/ops/technology` 기술 연동 보드
